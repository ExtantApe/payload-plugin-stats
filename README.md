# payload-plugin-stats

Stats for Payload: admin-only counts of users by role, position and other fields, with no names, emails or IDs, and small groups hidden. Coming soon.

> **Status: coming soon.** This repo holds the name, the license and the plan's first decisions. There's no code yet, so nothing has been tested, and nothing is on npm.

## What it will do

- Count users by role, position and other fields you choose, as totals and broken down.
- Show the counts only to admins.
- Never show a name, an email or an ID, only numbers.
- Hide any group small enough that a count could point to one person.
